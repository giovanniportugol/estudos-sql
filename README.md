# Estudos SQL

Repositório criado para registrar meus estudos acadêmicos em SQL e fundamentos de banco de dados.

## Sobre

Sou estudante de Análise e Desenvolvimento de Sistemas e estou em transição para a área de Tecnologia da Informação.

Este repositório tem como objetivo organizar exercícios simples de SQL, com foco em:

- Criação de tabelas
- Inserção de dados
- Consultas básicas
- Filtros com WHERE
- Ordenação com ORDER BY
- Atualização de registros
- Exclusão de registros
- Fundamentos de banco de dados

## Exercícios

- `primeira_tabela.sql` — criação de uma tabela de alunos, inserção de registros e consulta com SELECT.

## Objetivo

Demonstrar minha evolução nos estudos de banco de dados, praticando comandos SQL fundamentais e desenvolvendo raciocínio lógico para manipulação de informações.
